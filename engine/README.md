## 每交易日的工作方式

时区为北京时间 `Asia/Shanghai`，按交易所交易日历跳过周末、节假日。无法确认交易日或缺少有效数据时应标为等待，不伪造当日报告。

| 北京时间 | 目标工作 |
| --- | --- |
| 08:00 | 收集行情、公司公告与新闻，记录来源、时间和未完成项目 |
| 09:00 | 发布今日买入研究及前一交易日建议的卖出参考 |

Actions可能排队或延迟，不能保证09:00整点发布。页面显示真实时间；09:30后补跑不新生成当天买入建议，仍跟踪前日建议的卖出参考。没有已核验的早间采集、新闻和合格模型时不强行推荐。

每笔建议独立跟踪两个交易日：D1 是建议买入日，D2 是下一交易日的卖出参考日；节假日顺延。今天可以研究新的股票，同时为前日建议给出卖出参考。跟踪清单不代表用户实际持仓，未买入者可以忽略对应卖出参考。

默认周期收益口径是 **买入日开盘 → 下一交易日收盘（研究近似）**。页面同时保留下一交易日预测摘要，并显示模型期限、经验区间、验证平均误差与样本数。遵守 A 股 T+1；参考价格不能保证触及、成交或盈利。

旧的浏览器交易执行方案和旧定时入口不属于当前产品，不应调用旧 `agent_runner.py` 或重新启用遗留交易任务。当前发布验收应核对只存在获授权的研究计划，不能把旧任务记录当成新云端调度的证据。

## 覆盖与推荐

全沪市证券尽可能纳入研究，具体数量随证券列表变化。界面分别列出研究总数、有效数量、待补齐数量、推荐排除的指标股数量，以及非指标研究范围与有效数量。**排除推荐不等于缺少研究数据。**

主榜默认显示非指标股，参考开关可以查看排除项。排除口径由后端版本及 `exclusion_policy` 决定，不凭股票名称臆造“所有指标股”的完整名单。唯一首选只从数据有效、未被排除、技术条件及预测验证同时通过的候选中产生；非指标有效覆盖门槛按当前后端与前端一致规则执行。无合格候选时不强行推荐。

当日报告如提供未通过验证的候选价位，页面标为“仅研究价位”，不构成买入建议。缺失值保留为空，停牌、陈旧行情、预测失败和样本不足应明确提示。

长线研究逐步扩展到非指标股，显示已处理、待处理和财务完整性，不把部分研究当成全市场完成。仅 `eligible=true` 且未过期的条目进入合格候选，其余保留在参考区。ROE 使用最近已公告完整年度的加权值，最新财报期与公告日分别列示。

## 如何理解结果

预计涨幅是研究模型估计，不能保证准确。经验区间不是校准后的置信保证，验证方向准确率不是个股未来上涨概率。免费数据源可能延迟、限流、修订或中断；需核对公告、实时报价及自身风险承受能力。

个股详情中的两交易日规则回测独立于岭回归预测，按D1买、D2卖及成交限制模拟；没有模拟用户实际手动决策，不能据此声称当前预测模型的真实绩效。

历史曲线和指标使用前复权研究价格，买卖参考应核对当前未复权价。模型收益近似、交易费用、滑点、跳空、涨跌停与个人实际成交均可能使结果产生差异。

## 本地备用与开发

Windows 64位完整迁移包已含官方便携Python，解压后无需安装依赖，运行 `start.cmd`，打开 `http://127.0.0.1:8765`。其他环境使用 Python 3.10 或更新版本运行 `python app.py serve --open`；本地程序使用 Python 标准库。本地地址不等于互联网部署，也不能由手机通过互联网直接访问。

常用检查：

```text
python app.py status
python -m unittest discover -s tests -v
node --check static/app.js
```

数据主要保存在 `data/market.sqlite3`。本地接口按回环地址使用，不直接开放到公网。当前部署适配位于相邻的 `ashare-github`，静态网页由研究JSON导出。`ashare-cloud`保留历史Sites/Cloudflare原型与原绑定，未部署；当前不继续该路线，也不重复create_site。
